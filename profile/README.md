*Global Mapper is a geographic information system (GIS) application for Windows that brings vector, raster, and elevation data together in one working map.*

Global Mapper for Windows is used by GIS analysts, surveyors, and environmental professionals who need to combine spatial data from many different sources into a single, navigable map. Rather than opening a separate program for every file type, Global Mapper loads shapefiles, imagery, and elevation grids into one workspace where they can be measured, edited, and analyzed together.

## Why people use it
| Feature | What it does for you |
|---|---|
| Broad format support | Load vector, raster, elevation, and point cloud data without converting files first |
| Terrain analysis tools | Generate contours and run viewshed and watershed calculations on elevation data |
| LiDAR point cloud handling | View and classify LiDAR data alongside your other map layers |
| Coordinate system reprojection | Bring data captured in different projections into one consistent map |
| Measurement and digitizing tools | Measure distance and area, and create or edit vector features directly on the map |

## Getting going
After Global Mapper opens, load your first dataset from the file menu and let the application place it on the map; from there, add more layers, reproject anything that doesn't line up, and start measuring or generating contours once your terrain data is in place.
